# Codex 重置雷达 PRD

阶段：Super Dev docs
状态：等待确认

## 目标

做一个可分享的中文网页，帮助 Codex 重度用户判断 usage limits 是否即将重置，并给出中国时间窗口。

## 用户

- Codex 高频用户
- 社群运营者
- 需要给别人转发一个可信状态页的人

## 核心需求

1. 首页 5 秒内看懂当前概率。
2. 必须展示最强证据和 X 跳转。
3. 必须给中国时间窗口，不把美国/欧洲时间误写成中国早上。
4. 不依赖 X token 也能部署运行。
5. 每个功能都是真实链路，不放假提醒、假开关、无效设置。

## MVP 功能

- 当前重置概率
- 最强信号
- 每日概率曲线
- 监控人：Tibo / Sam
- 重置路线时间线
- `/api/current` 公开 JSON
- `/api/sources` 免费源健康检查

## 非目标

- 不做登录
- 不做用户个人通知
- 不承诺是官方状态
- 不使用隐藏 Cookie 抓取用户账号

## 成功标准

- 无 X token 时仍可稳定显示公开 radar + RSS 探测结果。
- 免费 RSS 实例失败时页面不会空白。
- 所有证据能跳转到 X。
- 中国窗口展示正确。

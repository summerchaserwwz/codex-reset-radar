# Codex 重置雷达 UIUX

阶段：Super Dev docs
状态：等待确认

## 方向

中文分享页，不是内部控制台。

参考 VoltAgent / Vercel 的黑底开发者工具气质，但不复制品牌。页面要克制、清楚、证据优先。

## 页面结构

1. 顶部：产品名、信号状态、更新时间、复制链接。
2. 左上：概率仪表盘和中国窗口。
3. 左下：最强信号 X 卡片。
4. 右上：每日概率曲线。
5. 右下：监控人。
6. 下方：重置路线时间线。

## 视觉约束

- 无闪烁光效。
- 概率光圈只保留柔和单圈。
- 不做假开关。
- 不放无用来源卡片。
- 字体不要过大。
- 状态颜色允许更丰富：高概率绿，中概率黄，低概率蓝，反向信号红。

## 文案

短中文：

- 速蹬
- 盯紧
- 悠着点
- 免费 RSS 源
- 中国主观察
- 最强信号
- 重置路线

## 图标

只用 Lucide React，不使用 emoji。
